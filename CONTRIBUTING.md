# Contributing

Contributions should improve this educational, non-commercial study. Start with
the README and architecture notes. Keep gameplay, presentation, and evidence
separate, and explain what a change teaches or fixes.

1. Open an issue describing the observable problem or proposed improvement.
2. Make a focused branch. Preserve real damage, cooldown, collision and input behavior.
3. Run the static validator and relevant Godot smoke tests listed in BUILDING.md.
4. Include game-only screenshots for visible changes and disclose staged test conditions.
5. Record asset origin and license. Do not submit extracted game assets, cracked
   tools, credentials, private conversations, account details, or machine-specific paths.
6. Submit a pull request with the result, tests, and remaining limitations.

By submitting original contributions, you offer them under this repository's
[license](LICENSE), to the extent you have the right to do so. Third-party work
must be separately attributed and compatible with its own terms. Do not claim
an externally sourced file is original or AI-generated.

Use respectful, specific feedback. Report gameplay defects independently from
visual fidelity preferences. This is a small fan study, not a full game roadmap.
